Kerala Migrant API

An infrastructure-layer API designed to operationalize migrant worker data in Kerala — clean, queryable, and policy-ready.

This project exposes a RESTful backend that centralizes migrant-related information (registration, demographics, work sectors, movement, and welfare touchpoints) into a single, programmable surface. The intent is simple and ruthless: turn fragmented records into actionable intelligence.

Why This Exists

Kerala hosts a large, mobile migrant workforce. Data about them is often:

Scattered across departments

Stored in incompatible formats

Manually processed

Impossible to analyze in real time

This API is the unifying spine. It ingests raw inputs, normalizes them, and serves them through deterministic endpoints — ready for dashboards, analytics pipelines, and policy engines.

Tech Stack
Layer	Technology
Backend	Python (Flask)
Database	MongoDB
API Style	REST
Data Format	JSON
Auth (optional)	Token / JWT

Designed to be lightweight, extensible, and boring in production — exactly how infrastructure should be.
